# SOET Connect — Vite Frontend Workspace

This directory contains a separate React application bootstrapped with Vite.

The repository's primary Next.js application is maintained in [`SoETAlumniPortal/`](../SoETAlumniPortal/). For the complete project architecture and local setup instructions, see the [root README](../README.md).

## Run this Vite workspace

```bash
npm install
npm run dev
```

## Available scripts

- `npm run dev` — start the Vite development server.
- `npm run build` — create a production build.
- `npm run preview` — preview the production build.
- `npm run lint` — run ESLint.
